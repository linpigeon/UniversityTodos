### 2. 宿舍水费

在电费页面下方增加“宿舍水费”区域：

- 电费页点击“查询水费”后，Windows 先完成 WebView Adapter 初始化并发起导航，再将宿主移出屏幕，避免隐藏导致 Adapter 不创建、45 秒无导航后错误回退前台。后台查询不持续显示统一认证网页；45 秒未完成时在 设置 → 账号 显示同一认证页面并继续手动登录。

- 默认仅显示账期结束日期在 `settings.json` 的「学期第一周周一」及之后的冷热水用量、费用、合计、房间和更新时间，包括结束日晚于今天的在途账期；本学期无账单时直接返回空结果，不反复查询或回退登录。页面就绪后立即开始读取，轮询间隔为 250ms，保留表格稳定等待，避免过早读取旧账单。

### 3. 凭据加密与一键登录

`设置 → 账号` 集中管理统一认证、学习通、批改网凭据。雨课堂和教务系统已取消账密托管及一键登录，只使用手动 WebView 登录。

- Windows：DPAPI，限本机当前 Windows 用户解密。
- Android：Keystore + AES/GCM，密钥不离开系统密钥库。
- 不支持安全存储的平台拒绝保存，不明文降级。
- 支持保存、清除、一键登录和会话复用；各平台账密自动填充和直接 POST 的验收状态见后文，不能仅凭“已实现”视为登录成功。

核心文件：

- `UniversityTodos/Models/CredentialFile.cs`
- `UniversityTodos/Services/CredentialStore.cs`
- `UniversityTodos/ViewModels/PlatformCredentialViewModel.cs`
- `UniversityTodos.Android/AndroidCredentialProtection.cs`

以下凭据文件均纳入备份：

- `water-credentials.json`
- `chaoxing-credentials.json`
- `pigai-credentials.json`

备份限制：备份 ZIP 包含敏感凭据密文，但 ZIP 本身没有额外加密，必须妥善保管。DPAPI 凭据只能由原 Windows 用户解密；Android 凭据依赖原 Keystore 密钥。换机、换 Windows 用户或密钥不可用时，需要重新保存凭据并登录，不能把备份当作可跨设备迁移的明文账密库。

### 5. 学习通与批改网静默登录

已实现：

- 学习通：先由 `ChaoxingDirectLoginService` 使用 `fanyalogin`，任何直接登录失败都会继续进入后台官方登录页，自动填写并提交账密；45 秒未完成或无法提交时显示同一 WebView，由用户处理点选验证、双因素、扫码或手动登录。
- 批改网账密：先由 `PigaiDirectLoginService` 按站点 RSA 公钥加密为 `password_encrypt`，失败后进入后台官方表单。站点专用脚本使用 `#username`、`#password`、`#ulogin`，不再依赖匹配不到登录按钮的通用选择器。
- 批改网微信：新增“微信授权登录”，直接显示官方 `/d3/weixin/wxlogin.html`，由用户亲自确认授权，通过现有登录探测和 Cookie 捕获完成会话；需要绑定或扫码时直接在当前页面继续。
- Android 不启用账密后台登录；Windows 和 Android 的微信授权都直接显示官方页面。

注意：上一阶段提供的统一认证账密被学习通、批改网拒绝，因此**协议与后台页面链路已实现，但成功登录尚未证明**，需要使用各平台自己的有效账号验证。

## 常用命令

以下命令均从仓库根目录执行。运行桌面项目需要 .NET 10 SDK；Android 构建还需要已安装匹配的 Android workload。`--androidcheck`、`--electricity-toastcheck` 和 `--watercheck` 也可在构建输出目录中对 `UniversityTodos.Desktop.exe` 使用相同参数。

```powershell
# 序列化与业务自检
dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --jsoncheck

# 公开登录页首轮加载与取消异常自检，不提交账密、不唤起微信
dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --logingatecheck

# 水费后台宿主导航自检，不使用凭据
dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --watersilentcheck

# 冷启动统一认证与账单读取，使用本机已加密凭据，不输出账密或 Cookie
dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --watercoldcheck

# 桌面端模拟 Android 移动外壳的布局审计；报告和截图写入指定目录
dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --androidcheck <输出目录>

# 会真实投递 Windows 系统通知
dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --electricity-toastcheck

# Android 构建
dotnet build UniversityTodos.Android/UniversityTodos.Android.csproj -c Release
```

`--watercheck` 会真实访问学校统一认证和水费页面，必须从当前进程环境变量读取账号；缺少任一变量会以退出码 2 结束。下面通过 `Read-Host` 避免把真实账密直接写进命令历史，输入密码时终端会回显，应在私有终端中操作：

```powershell
$env:ZCST_WATER_ACCOUNT = Read-Host "统一认证学号"
$env:ZCST_WATER_PASSWORD = Read-Host "统一认证密码"
try {
  dotnet run --project UniversityTodos.Desktop/UniversityTodos.Desktop.csproj -- --watercheck
} finally {
  Remove-Item Env:ZCST_WATER_ACCOUNT, Env:ZCST_WATER_PASSWORD -ErrorAction SilentlyContinue
}
```

Visual Studio 正在调试时可能锁定默认输出目录的 DLL，不要强杀用户进程。使用**绝对** `OutDir`，避免相对路径被 MSBuild 分别解析到各项目目录下：

```powershell
$probe = Join-Path $PWD ("publish/_probe/handoff-" + [guid]::NewGuid().ToString("N"))
dotnet build UniversityTodos.Desktop/UniversityTodos.Desktop.csproj --no-restore "-p:OutDir=$probe/"
& (Join-Path $probe "UniversityTodos.Desktop.exe") --jsoncheck
```
